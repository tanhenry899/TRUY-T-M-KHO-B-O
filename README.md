# TRUY TÌM KHO BÁU – HÀNH TRÌNH CHINH PHỤC TRI THỨC

> **HỌC TẬP VUI – KHÁM PHÁ GIỎI – CHINH PHỤC KHO BÁU!**

Game phiêu lưu giáo dục 3D (Three.js / WebGL / React / TypeScript) dành cho học sinh tiểu học **Lớp 1, 2, 3, 4, 5**, hỗ trợ tổ chức ôn tập, củng cố kiến thức và thi đua đồng đội môn **Toán** và **Tiếng Việt** trên máy chiếu lớp học cũng như thiết bị cá nhân.

## Tính năng nổi bật
- **Thế giới Đảo Kho Báu 3D thực thụ**: 5 khu vực riêng biệt (Rừng Khởi Đầu, Cầu Ánh Sáng & Thác Nước, Hang Động Bí Ẩn, Núi Lửa Thử Thách, Đền Cổ Đảo Kho Báu) cùng sóng biển động, mây trôi, cây dừa lay động và Rương Kho Báu Vàng phát sáng.
- **Nhân vật MC Nhà Thám Hiểm 3D**: Tạo hình nhiều khớp động với 7 trạng thái biểu cảm (`idle`, `talking`, `happy`, `sad`, `excited`, `pointing`, `celebrating`) kết hợp giọng đọc tiếng Việt `SpeechSynthesis`.
- **8 Màn hình hoàn chỉnh**: Trang chủ, Thiết lập trò chơi (15 tùy chọn giáo viên), Bản đồ kho báu 3D, Nhân vật MC 3D, Giao diện câu hỏi máy chiếu + 4 thẻ 3D, Hệ thống trợ giúp (50:50, Gợi ý, Nghe đọc, Đổi câu, Bỏ qua, Tạm dừng, GV xác nhận), Mở rương kho báu 3D, Bảng kết quả & Báo cáo CSV/In ấn.
- **Ngân hàng câu hỏi độc lập**: Có sẵn bộ câu hỏi chuẩn Toán & Tiếng Việt lớp 1–5 (kèm hình minh họa SVG trực quan: đồng hồ, phân số, hình học, cân thăng bằng, đếm hình, bảng biểu, đoạn văn). Hỗ trợ thêm/sửa/xóa, lọc, nhập/xuất CSV UTF-8, mẫu Excel, sao lưu/khôi phục JSON, đóng gói ZIP và tạo bản nháp bằng AI (giáo viên bắt buộc kiểm duyệt trước khi lưu).
- **Chạy Offline 100%**: Không phụ thuộc CDN, phông chữ tiếng Việt và âm thanh Web Audio được đóng gói cục bộ, dữ liệu lưu bền vững bằng IndexedDB & LocalStorage.

## Hướng dẫn chạy cục bộ
```bash
npm install
npm run dev
```
Mở trình duyệt tại `http://localhost:3000`.

Để đóng gói bản tĩnh hoặc chạy sản phẩm:
```bash
npm run build
npm start
```
